## 独立静态验收

独立审查者 `/root/review_skill_contract` 读取当前四个运行包文件，在独立上下文检查以下 8 组情景，未接入宿主或模型 API：

| 情景 | 静态推导 |
| --- | --- |
| Luna 支持 low/medium/high，配置 high | 所有未覆盖角色使用 high；长期偏好为 high |
| 配置 high，用户通用 low、验收 high | 实现 low、验收 high；长期记录仍为 high |
| 配置字段缺省 | 无用户覆盖时偏好 medium |
| 项目禁止创建 .crazy-luna | 不写状态，说明未保存，继续有依据的规划 |
| 用户未给具体任务 | 询问目标，不初始化状态或占位执行记录 |
| Haiku 派发可用但不能调节推理 | 省略推理参数并说明限制；用户强制档位无法满足时阻塞相关角色 |
| 仅有主模型选择器，无子 Agent 接口 | 不产生自动派发参数；默认 null，提供手动会话交接 |
| 配置 null 或未知非空档位 | null 为配置错误；未知档位须解析，不能作为已确认参数派发 |

审查者指出未知档位时的本地状态组合不够明确。随后补齐：长期默认参数无法解析时，按已确认不支持或证据不足分别记 unavailable/unknown，default_model 和 reasoning_parameters 为 null；临时覆盖失败不使有效长期默认失效。审查者再次读取该改动后复核通过。上述结论均为规则推导，不是模型执行证明。
