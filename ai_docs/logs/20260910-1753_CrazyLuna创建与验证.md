## 格式验证

使用现有 Ruby YAML 解析器，检查 YAML、命名和目录一致性、frontmatter 字段、简介长度、UI 默认 Prompt、代码围栏、未完成脚手架和空白。检查不是简单搜索几个业务关键词。

可在项目根目录复现：

```sh
ruby - <<'RUBY'
require 'yaml'
require 'pathname'
root = Pathname.new('skills/crazy-luna')
source = root.join('SKILL.md').read
match = source.match(/\A---\n(.*?)\n---\n/m) or abort 'missing frontmatter'
meta = YAML.safe_load(match[1])
abort 'frontmatter shape' unless meta.is_a?(Hash) && meta.keys.sort == %w[description name]
abort 'skill name' unless meta['name'] == root.basename.to_s && meta['name'].match?(/\A[a-z0-9]+(?:-[a-z0-9]+)*\z/) && meta['name'].length < 64
abort 'description' unless meta['description'].is_a?(String) && meta['description'].length.between?(1, 1024) && !meta['description'].match?(/[<>]/)
abort 'unfinished scaffold' if source.match?(/^\s*\[TODO:/)
abort 'fence mismatch' unless source.scan(/^```/).length.even?
ui = YAML.safe_load(root.join('agents/openai.yaml').read).fetch('interface')
abort 'UI short description' unless ui.fetch('short_description').length.between?(25, 64)
abort 'UI prompt' unless ui.fetch('default_prompt').include?('$crazy-luna')
[root.join('SKILL.md'), root.join('agents/openai.yaml')].each do |file|
  content = file.read
  abort "whitespace: #{file}" if content.match?(/[\t ]+$/) || !content.end_with?("\n")
end
puts "PASS: YAML, frontmatter, name, UI metadata, fences, scaffold, whitespace (#{source.lines.length} lines)"
RUBY
```

格式结果：退出码 0，`PASS`，入口 146 行。原版 Python `quick_validate.py` 没有运行：当前项目没有 Python venv，已检查的 pyenv 基础环境也没有 PyYAML；本次没有新增依赖或测试设施，也没有运行系统 Python。Ruby 检查与行为演练不应描述成原版验证器通过。
